Food Exchange Platform
A community-driven web application designed to help people share surplus food, reduce waste, and connect with neighbors. Built with Next.js and powered by v0 for rapid no-code development.

🚀 Overview
The Food Exchange Platform enables users to:

List available food items for exchange or donation.

Browse nearby listings and request exchanges.

Build trust through user profiles and ratings.

Reduce food waste while fostering community connections.

🛠️ Tech Stack
Next.js – React framework for building scalable web apps.

v0 – No-code AI-assisted development platform.

Deployment: Automatic with every merge to main.

⚙️ Getting Started
Run the development server:

bash
npm run dev
# or
yarn dev
# or
pnpm dev
Open http://localhost:3000 in your browser to view the app.
Edit app/page.tsx to start customizing — changes update automatically.
